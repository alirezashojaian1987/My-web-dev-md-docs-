HTML contains several elements for defining text with a special meaning.

##### HTML formatting elements
- `<b>` - Bold text
- `<strong>` - Important text(also in bold)
- `<i>` - Italic text
- `<em>` - Emphasized text(also in italic)
- `<mark>` - Marked text
- `<small>` - Smaller text
- `<del>` - Deleted text
- `<ins>` - Inserted text
- `<sub>` - Subscript text
- `<sup>` - Superscript text
