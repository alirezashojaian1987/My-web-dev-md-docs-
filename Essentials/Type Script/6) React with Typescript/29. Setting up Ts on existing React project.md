Now having a Jsx based react project from before, we want to learn that how can we turn it into the Tsx format based project.

Needing the compiler, type checking in the IDE and more, we need to run some commands for our pre Js based project.
##### Installation
Run these commands:
```bash
npm install typescript @types/react @types/react-dom --save-dev
npm install @typescript-eslint/eslint-plugin --save-dev
npm install @typescript-eslint/parser --save-dev
```
Types are important for our react project in order to turn it in Ts based one.
The `eslint` or the `parser` are used for a better coding experience in the IDE.

