Now that we learnt about the Typescript, it's good to have type safety and type checking in our React project.

Also typescript will help you have a better auto completion experience in a react project specially that you have so many components.

Now let's see a Ts based react project:
##### Installation
Run this command:
```bash
npm create vite@latest
```

Then type your project name.

Then the package name.

Select **React** for the framework.

Then choose **Typescript** for the variant.

Done. Now go to that folder in the terminal to start your coding.
##### Differences 
One of the key differences you can see now is that all of your main files are `tsx` format instead of `jsx`.

Other important thing to mention is that we said that Typescript has a compiler, and we know that Ts codes never get executed on browsers directly. Node servers only know JS. So we need the compiler to turn our code into Js and then run our project on the server.
