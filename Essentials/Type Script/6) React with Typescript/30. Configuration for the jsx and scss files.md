##### Scss module importation
If you open your components pages, you see that it is showing error on using this:
```tsx
import styles from "./comp.module.scss";
```
To solve this you can create a file in the project folder called `global.d.ts`
Then use this code:
```ts
declare module "*.module.scss";
```
Then in the config.json file, we need to give it's address.
In the `"include"` section:
```ts
"include":["src","global.d.ts"],
```
Then you need to start and stop your project.
