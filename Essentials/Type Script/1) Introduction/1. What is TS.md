##### What is TS
JS as we learnt, is a dynamic type language and TS helps us adding the **static typing**  to JS.(We'll talk about them later).

TS is an open source programming language and it's different from packages of languages like React. It's not a framework, nor a library. TS is a language that it's base is JS. Technically TS is a superset for JS. What we mean by superset is the main core of this language is JS and TS extends it.

It adds some features and abilities to JS's abilities. 

TS helps us to face lesser errors. it lets us debug before running a program. 

JS is a language that doesn't support compilers and it's code can't be compiled. When running a JS code you may face the errors and these errors cannot be found unless running the program.

TS helps us with this before the runtime. 

And finally it's for a better and organized JS based code.
