By the words above, we don't mean to tell there are weak languages or strong languages.
Strong and weak are based on typing.

For example, python is a strong dynamic language, whereas JS is a weak dynamic language.
```js
function add(a,b){
	return a+b;
}

function mult(a,b){
	return a*b;
}

console.log(add(5,"10")); // 510
console.log(mult(5,"10")) //50
```
In the example above when giving one num and one string to the add function, because of the + operator changes it's behavior during when adding a num and string, it returns us 510 which is concating. This operation is called type coercion which changes the data types in order they can be together. In add function, it changes the 5 into a string.

In function, `*` is a mathmetic op. Which JS now turns the `"10"` into a number.
But in Python, when doing the example above, you'll face error.

So based on this, weak types have type coercion while the strong ones don't.
