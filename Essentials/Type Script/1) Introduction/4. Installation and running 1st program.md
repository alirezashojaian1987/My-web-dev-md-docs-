First you need to install the TS compiler in your system which can be done in 2 ways, for dev environment(which is by command and only makes that environment have ts) Or globally in your system. 
##### How to install
Run this command in your terminal:
```bash
npm i -g typescript
```
After it, you can make sure of the installation and it's version by this command:
```bash
npx tsc -v
```

Now the earlier practice:
```ts
function add(a:number,b:number){
    return a+b;
}
  
console.log(add(5,"10"));// Now because of ts, vscode will show the error here that tells you that you used a NaN value.
```
##### How to compile and run the code
In your terminal, write this:
```bash
npx tsc .\filename.ts
```
Which will compile it, run it and then a new js file will be created in that directory(Ts turns it's code to js for browsers to understand it.).
*Note:* If you only need to run it to see the result, you can use `node` that is used in running Js file.

Afterwards you can use the old node + filename command.

Running the code above will result in this error:
```bash
TSp.ts:5:19 - error TS2345: Argument of type 'string' is not assignable to parameter of type 'number'.
```

##### Config TS compiler
As mentioned before, after the TS file compiles and runs, a JS file will be created. But sometimes some syntaxes in the TS will transform into old syntaxes in JS, we can prevent that by running this command:
```bash
npx tsc --init
```
Which will create a `tsconfic.json` file. There will be some configs. You don't need to know about all configs.
After that use `npx tsc` only.
You can define your ES version in the target attribute in the config file.

If you want our JS file to be created in another folder after the code compilation, find the outDir config and define it. 
```json
"outDir":"./Dist",
```
Which will create a new folder.
