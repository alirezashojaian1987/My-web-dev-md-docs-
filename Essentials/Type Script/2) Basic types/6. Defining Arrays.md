Now to declare and define an array.
```ts
const nums:number[]=[1,2,3,4];
const nums2:number[]=[1,2,3,'4']; // This will show error cause we declared that this is an array of nums.
```
In JS we could add any data types into our arrays. We need Ts's type checking in order that no error occur during our array method. Imagine using reducer array method to get a total of nums and a wrong put object inside the array, which will result in failure.

The second method of declaring arrays:
```ts
const nums:Array<number>=[1,2,3];
```
