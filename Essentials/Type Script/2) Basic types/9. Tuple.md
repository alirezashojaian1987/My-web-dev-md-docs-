Tuple is an array but with a constant size.
```ts
const user:[number,string]=[1,"Ali"];
//user[0].
//user[1].
```
Both of the `.`s above will show the number and string methods.

Now this is a tuple, an array with the constant size of 2.
Using `user[2]` will show us 2 errors. It's undefined and the size must be 2.

Now another example:
```ts
const scores:[string,number[]]=["Ali",[10,19,18,20]];
```
You can assign as many nums as you want for the array.

Remember, tuple has array methods. Using methods like push, will turn your tuple to array cause there'll be a new var.
