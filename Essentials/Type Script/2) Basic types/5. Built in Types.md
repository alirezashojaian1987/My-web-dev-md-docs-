As said before, Typescript is a super set for JS. It used JS's main cores and then added some other features to it.
We learnt that there are 2 data types in JS. Primitives(like num, string, bool, undefined, null) and non-primitives(reference types) like(arrays, objects, functions which were all objects).

##### TS new data types
There are some new data types added to JS by TS: 
`any, unknown, never, tuple, enum`.
We'll talk about them later.
##### How to define vars now in TS?

**Number**
```TS
let num1:number=1000;
num1=500;
num1="500"; //It will show you an error because we declared it as a num
```

*Note:* If your number is very long, you can separate it by underlines in TS:
```ts
let num:number=12_311_000_234
```
It helps with the num's readability by the users.

**String**
```ts
let text:string="Testing TS";
```
Using `.` after the string var will show you the methods.

**Boolean**
```ts
let isTrue:boolean=false;
```

**Null**
```ts
let nullVar:null=null;
```

**undefined**
```ts
let undefinedVar:undefined=undefined;
```
*Note:* You don't have to assign the undefined value to the undefined type var.

*!Note:* If you don't give the vars their defined type but you assign a value to them, TS will recognize their type.

*!Note:* If not given any type or value to the var, it's type will be `any` which helps you kinda get away with the TS's **types checking**, which is not recommended.

**any**
```ts
let anyvar:any=true;
let anyvar2:any=2;
```
If you hover your mouse on them, it won't show the bool or the num class types, cause it's defined with any.
For the undefined and null, if you assign only the values to them, it will show any., unless you declare that they are null or undefined.
