This function returns a number type var. You can hover on it to see it. But now have this example:
```ts
const calcDiscount=(price:number,discountPer:number)=>{
    if(discountPer<100) return 10;
}
```
Now if you hover on the function, you'll see it can return a number or an undefined value.
It's because if the condition fails, there won't be any return, so your function might get into error.
So be careful that your function should return s.th. You can also define that what type your function returns. 
```ts
const calcDiscount=(price:number,discountPer:number):number=>{
    return 10;
}
```
After this, you can't return any other type value.

```ts
const calcDiscount=(price:number,discountPer:number)=>{
    if(discountPer>=100) return 0;
    const discountVal=(price*discountPer)/100;
    const finalVal=price-discountVal;
    return finalVal;
}
const value=calcDiscount(10000,30);
```
