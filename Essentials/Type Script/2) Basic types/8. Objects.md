```ts
const car={
    brand:"Toyota",
    model:"Prado",
};
  
car.year=2022;
```
When using the code above, vscode shows this error that the year does not exist in the car object.

In Ts it's better to define our objects better, cause objects can contain vars and functions and...
```ts
const car:{
    brand:string;
    model:string;
    year:number;
}={
    brand:"Toyota",
    model:"Prado",
};
  
car.year=2022;
```
So this is the common object defining in TS, now the only little problem is left is that the year is still not defined.
But hey, sometimes we want to assign a value to it later, so how can we do it?
1st way is to assign a num like 0 to in in the object which is, well...

Again we can use the `?` mark:
```ts
const car:{
    brand:string;
    model:string;
    year?:number;
}={
    brand:"Toyota",
    model:"Prado",
};
  
car.year=2022;
```
But using this mark a lot is not recommended. It's better to be used for a real logic.

##### Making your object values unchangable
To do so you need to use the `readonly` keyword. This will make your object values unchangable.
You can't assign another value to that var later.
```ts
const car:{
    readonly brand:string;
    model:string;
    year?:number;
}={
    brand:"Toyota",
    model:"Prado",
};
  
car.year=2022;
car.brand="Tesla"
```
##### Defining methods in our objects
We know that we can add a method or a var to our object after the declaring even if it's not defined in the object.
But in Ts, it will show an error.
However, when compiled, the code turns to Js and it will work.
```ts
const car:{
    readonly brand:string;
    model:string;
    year?:number;
}={
    brand:"Toyota",
    model:"Prado",
};
  
car.year=2022;
car.brand="Tesla";
car.brake=()=>{
	console.log("Breaking");
}
```
This code was ok in js, but not now in the Ts.

To define a method in our Ts object:
```ts
const car:{
    readonly brand:string;
    model:string;
    year?:number;
    break?:()=>void;
}={
    brand:"Toyota",
    model:"Prado",
};
  
car.year=2022;
car.brand="Tesla";
car.break=()=>{
	console.log("Breaking");
}
```

**Defining updater methods for object's vars:**
```ts
const car:{
    readonly brand:string;
    model:string;
    year?:number;
    break?:()=>void;
    updateYear?:(newValue:number)=>void;
  
}={
    brand:"Toyota",
    model:"Prado",
    year:2019,
```
