Enum doesn't exist in Js. It's in some languages like C#. 
```ts
const first=1;
const second=2;
const third=3;
const fourth=4;
```
Now to write them in an enum var:
```ts
enum Nums{
	first,
	second,
	third,
	fourth,
}
```
They will be assigned values from 0 to the last element that here can be 3.
You can set a desired value to the first one, so the sequence continues from there.

When compiling this code, it will turn into a weird code, but don't worry. You won't need it.

```ts  
enum Nums{
    first,
    second,
    third,
    fourth,
}
let myNum=Nums;
let myNum2:Num=Nums.second;
```
myNum will get a random value.

You can give string values to enums, but then you need to give the others as well. 
```ts
enum ButtonSizes{
	small="sm",
	medium="md",
	large="lg",
	x_large="xl",
}

let btnSize:ButtonSizes=ButtonSizes.medium;
```

*!Note:* Remember, enums are immutable.
