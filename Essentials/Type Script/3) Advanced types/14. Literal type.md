It happened that we need some default values defined parameters to pass our functions as args.
```ts
type Wrestler={
    name:string;
    height:string;
    weight:86;
}
  
const wrestler={
    name:"Arthur",
    height:"2m",
}
wrestler.weight=90;// This will show error.
```
So we defined a default value for weight. Now we cannot assign other values to it.
We can also combine this with union:
```ts
type Wrestler={
    name:string;
    height:string;
    weight:86 | 92 | 80;
}
  
const wrestler={
    name:"Arthur",
    height:"2m",
    weight:86,
}
wrestler.weight=80 //It's ok
wrestler.weight=90;// This will show error.
```

Another example:
```ts
const handleStatus=(statusCode:number)=>{
	switch(statusCode){
		case 200:
			return "Ok";
		case 400:
			return "Bad request!";
		case 404:
			return "Not found!";
		case 500:
			return "Server has problem";
			
		default;
		break;
	}
}
```
The bad thing about this code is that it can get any number in any range, we don't want that here for this matter.
```ts
type StatusCode=200 | 400 | 404 | 500;
const handleStatus=(statusCode:number)=>{
	switch(statusCode){
		case 200:
			return "Ok";
		case 400:
			return "Bad request!";
		case 404:
			return "Not found!";
		case 500:
			return "Server has problem";
			
		default:
			return "It's not valid status";
	}
}
```
