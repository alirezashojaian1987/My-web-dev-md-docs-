```ts
let someData:any="This is a string";
someData.
```
When you use `.`, it won't show string methods, cause it's declared as `any` type.
But you can make that happen:
```ts
let someData:any="This is a string";
(someData as string).length;
```

Another example:
```ts
const username=document.getElementById("username");
username.
```
When you hover on it, you can see that Ts thinks it's either an HTML element or a null object.
But we want to use it as input, we need input methods. Cause this id we used can be from a input. But Ts doesn't know that.
So we can use type assertions in these matters:
```ts
const username=document.getElementById("username") as HTMLInputElement;
```
Now you can access input methods. 

*!Note:* When using type assertions, you must be sure that it's that type you defined, or it will result in error.
