Sometimes, the errors that can occur in JS are because of undefined values.
Like making array to null or object as well. Or passing null vars to functions and...
Which can result in crash.
```ts
const logger=(array:string[])=>{
    array.forEach((item)=>{
        console.log(item);
    });
};
  
logger(null);
```
Like this code for example. 

But now that we realized this can be possible, let's find a way to handle this problem when occurring.
```ts
const logger=(array:string[] | null | undefined):void | string=>{
    if(Array.isArray(array)){
        array.forEach((item)=>{
            console.log(item);
        });
    }
    else return "Array is needed";
};
  
logger(null);
logger(undefined);
```
