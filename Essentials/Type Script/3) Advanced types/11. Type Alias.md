Remember this code:
```ts
const car:{
    readonly brand:string;
    model:string;
    year:number;
    break?:()=>void;
    updateYear:(value:number)=>void;
}={
    brand:"Toyota",
    model:"Prado",
    year:2019,
    updateYear(val){
        this.year=val;
    },
    break(){
        console.log("Using breaks..");
    },
};
```
We mentioned earlier that this structure can be messy, even more if we continue adding things to it which will reduce it's readability.

And another problem is that if we want to use this object in another file, we have to write the definitions from the start again.

Ts provides a method to help us make this structure shorter and more readable.
##### Type Alias
This is a feature that helps us separate the types and make our object more organized.
```ts
type Car={
    readonly brand:string;
    model:string;
    year:number;
    break?:()=>void;
    updateYear:(value:number)=>void;
}
  
const car:Car={
    brand:"Toyota",
    model:"Prado",
    year:2019,
    updateYear(val){
        this.year=val;
    },
    break(){
        console.log("Using breaks..");
    },
};
```
It's better to name it in pascal case way(it's your choice).

Now it's better and easier to read, and we can export it and use it in other files. Just add `export` before `type Car...`
