We don't use it often, but there are circumstances that it can be needed, so let's get to it.

```ts
function runningProcess(){
	while(true){
		console.log("...");
	}
}

runningProcess();

console.log("Logging...");
```
We know that Js reads the code line by line, when this function gets called, Js wait until the calling process gets finished(which here won't). So it gets stuck here forever and the next lines won't be read.

Now let's talk about this function's type. You think it's void, but it isn't.
Because that it never gets out of the loop to check for any return.

This function's type is called `never`.
```ts
function runningProcess():never{}
```
When you declare this function as never, the rest of the code will be pale. Which means that vscode knows they won't run.
