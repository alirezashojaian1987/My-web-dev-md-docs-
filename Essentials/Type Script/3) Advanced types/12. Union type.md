There are times that we get some types as entry args in a function, will be different types,(can be num or string and...). How can we handle them and define their types.

```ts
const calculateDisc=(price,discount)=>{
    //
};
  
calculateDisc(1000,"15%");
//or
calculateDisc(1000,15);
```
Imagine user wants to give it both string and num as parameters, and make the function work.

To handle that, we can use union types.
The syntax will be like this:
```ts
const calculateDisc=(price:number,discount:string | number){
    //
};
```
This means it can be string or number. Now to handle the logic, we can use a technique called **Narrowing**. Which is for checking the types before taking actions:
```ts
const calculateDisc=(price:number,discount:string | number):number=>{
    if(typeof discount==="number"){
        return (price*discount)/100;
    }
    return (price*parseInt(discount))/100;
};
  
console.log(calculateDisc(1000,"15%"));
console.log(calculateDisc(1000,15));
```

*Note:* In the first it, if you use `.` after the discount, Ts knows it's a number type var and will show number methods.
*Note:* On the other hand, after the if, TS knows the discount is string. So it will show string methods.

*Note:* Union types can be limitless.
