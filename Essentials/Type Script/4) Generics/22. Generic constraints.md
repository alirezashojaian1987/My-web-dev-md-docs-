```ts
const mergeObjs=(obj1:Object,obj2:Object)=>{
    return Object.assign(obj1,obj2);
}
  
const newObj=mergeObjs({id:10,name:"Test"},{score:20,age:30});
  
newObj.
```
When using `.` above after the new object, it doesn't show any of the object keys.

Even if you use generics here, Ts won't know about the objects being objects.
```ts
const mergeObjs=<O1,O2>(obj1:O1,obj2:O2): O1 & O2=>{
    return Object.assign(obj1,obj2);
}
  
const newObj=mergeObjs({id:10,name:"Test"},{score:20,age:30});
```
How to solve this?
##### Generic constraints
```ts
const mergeObjs=<O1 extends Object , O2 extends Object>(obj1:O1,obj2:O2): O1 & O2=>{
    return Object.assign(obj1,obj2);
}
  
const newObj=mergeObjs({id:10,name:"Test"},{score:20,age:30});
newObj.
```

Another example:
```ts
const printError=<T extends {code:number, massage:string}>(error:T)=>{
    console.log(
        `Error code is ${error.code} and the massage is ${error.massage}`
    );
};
printError({code:404,massage:"User not found"});
```
or
```ts
interface printError{
    code:number;
    massage:string;
    status?:string;
}
  
const printError=<T extends printError>(error:T)=>{
    console.log(
        `Error code is ${error.code} and the massage is ${error.massage}`
    );
};
printError({code:404,massage:"User not found"});
```
