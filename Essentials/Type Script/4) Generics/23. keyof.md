```ts
const extractProperty=(obj:Object,key:String)=>{
    return obj[key];
};
  
const user={name:"Lil nigga", age:30, score:18};
  
const score=extractProperty(user,"score");
```
When putting `.` after the obj var, Ts doesn't know what is inside that object or what is it's type.
We can use generic types to solve this:
```ts
const extractProperty=<T,U extends T>(obj:T,key:U)=>{
    return obj[key];
};
  
const user={name:"Lil nigga", age:30, score:18};
  
const score=extractProperty(user,"score");
```
U is an object, we need the keys inside the T, so:
```ts
const extractProperty=<T,U extends T>(obj:T,key:U)=>{
    return obj[key];
};
  
const user={name:"Lil nigga", age:30, score:18};
  
const score=extractProperty(user,"score");
```
This means a key inside the T object.
```ts
const score=extractProperty(user,"score");
const test=extractProperty(user,"test");//This will show error
```
Now Ts knows there's no test key inside the object.
