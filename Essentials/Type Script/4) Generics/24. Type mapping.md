Imagine having an object with a lot of keys:
```ts
interface User{
    id:number;
    username:string;
    email:string;
    firstname:string;
    lastname:string;
    isActive:string;
    createdAt:Date;
    //And more
}
```
And you want to make all of the keys optional.
You can do it manually or using `type mapping`
##### Type mapping
```ts
interface User{
    id:number;
    username:string;
    email:string;
    firstname:string;
    lastname:string;
    isActive:string;
    createdAt:Date;
}
  
type optionalUser={
    [property in keyof User]?:User[property];
}
  
type readonlyUser={
    readonly [property in keyof User]?:User[property];    
}
  
const user:optionalUser={id:10,firstname:"Alireza"};
```
##### General type mapper for types
Now if you want to create a general type mapper function, for any objects, we can use generics:
```ts
type readonlyInterface<T>={
    readonly [property in keyof T]?:T[property];    
}
  
const user:readonlyInterface<User>={id:10,firstname:"Alireza"};
```
