Here are some useful utility types for generics(They are more):
##### Partial
```ts
interface User{
    id:number;
    name:string;
    age:number;
}
  
type PartialUser=Partial<User>;
```
This turns every key optional. We made this code in previous chapter, this is shorter. You can hover it to see how it's written.
##### Readonly
```ts
type readonlyUser=Readonly<User>;
```
##### Record
```ts
type Role="Admin" | "User" | "Guest";
type Access="Read" | "Write" | "delete";
  
type RolePermission=Record<Role,Access[]>;
const rolePermissions:RolePermission={
    Admin:["Read","Write","delete"],
    User:["Read","Write"],
    Guest:["Read"],
};
```
##### Pick
```ts
interface User{
    id:number;
    name:string;
    age:number;
}
  

type username=Pick<User,"name">;
```
This will pick the type you want from the object's key.
##### Omit
```ts
interface User{
    id:number;
    name:string;
    age:number;
}
  
type UserWithoutAge=Omit<User,"age">
```
This will return an object without the specified key.
##### Exclude
```ts
type Role="Admin" | "User" | "Guest";
type Access="Read" | "Write" | "delete";
  
type RolePermission=Record<Role,Access[]>;

type NewRole=Exclude<Role,"Guest">
```
