Here are some import and export techniques you can use while you are doing projects.
Imagine having a file with so many classes or functions or types and etc.
##### Import all of them at once
In the same folder:
`classes.ts`
```ts
class UserProfile{
    constructor(
        public id:number,
        public name:string,
        public email:string,
        public isActive:boolean,
    ){}
}
  
class Product{
    constructor(
        public id:number,
        public name:string,
        public price:number,
        public isStock:boolean,
    ){}
}
  
//and more
  
export {UserProfile,Product,/*and more*/};
```
`index.ts`
```ts
import { Product,UserProfile,/*and more*/ } from "./classes";
  
//your code
```
So as you can guess, you need to name all of the classes here that were exported in another file, so it's a bit messy and not appropriate.

In order to solve this problem:
```ts
import * as Classes from "./classes";
//your code
```
##### Re-exporting
Now imagine that every class has it's own file in the same directory, how can we import them in one place.
We can have a file that has all of the imports, and then we can use that one file to import the modules we need. This helps with a cleaner code.

In a file called `allClasses.ts`:
```ts
import {class1} from "./class1";
import {class2} from "./class2";
import {class3} from "./class3";

export {class1,class2,class3};
```
Now in the `index.ts`
```ts
import * as classes from "./allClasses.ts";
```
