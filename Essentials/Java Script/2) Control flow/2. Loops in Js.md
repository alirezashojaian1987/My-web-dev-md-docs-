As mentioned before, you may need to run a logic multiple times, so here loops come to rescue.
For example Having an array of names, and you want to print all of them, it's pretty dumb if you want to write console logs as much as the the size of the array.
##### for loop
```js
for(let i=0; i<=10; i++){
	console.log("Index:", i);
}
```
Which will print the indexes from 0 to 10. 11 console logs.
When a loop is running, the code will not continue unless the loop is over.

*!Note:* Be careful not to put an statement which can result in an infinite loop, which will pause and block the whole program.

*Example:*
```js
const students=["Alireza","Sohrab","Arman"];
for (let i=0; i<students.length; i++){
	console.log(students[i]);
}
```
Array's index start from 0.
##### While loop
While loop only accepts an statement, while in for loop we can define a variable as well.
```js
let i=0;
while(i<10){
	console.log(i);
}

while(true){
	console.log(i);
}
```
First while loop prints 0 to 9.
Second one prints 9 for infinite.

##### Do while loop
Do while is like while loop but with a key difference. It enters the loop for the first time, not considering the statement.
What this means is that the whole body runs first, after that, the statement for the loop will be checked. In other words, it will be run at least 1 time.

```js
let i=0;

do{
    console.log(i);
} while(i>0);
```
If it was a normal while loop, it would result in an infinite loop. But now that we are using the `do while`, the body will run for the first time, then the statement will be checked.
Here in this code, only one console log will be executed.

##### Continue & Break
These two can actually affect the loops behavior. 
`break` stops the loop scope.

`continue` skips the current step in the loop.
