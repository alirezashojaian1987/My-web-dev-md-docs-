There are times where we need to check an statement, before continuing.
Or we may want to deploy a block of code several times, or check all the elements inside a data structure(array, object and etc.).
##### Conditions in Js
To check conditional statements in Js, we have 2 approaches.
The first one being `if & else`.

The second one's called the `switch cases`.
```
if(condition){
	statement
}
or

if(condition){
	statement
} else {
	statement2 if condition fails
}
```
*Example:*
```js
const age=18;

if(age>=18){
    console.log("Able to get a driver licence");
} else {
    console.log("Not able to get a driver licence");
}
```

You can also use nested conditions:
```js
const age=18;
const hasCar=true;

if(age>=18){
    console.log("Able to get a driver licence");
    if(!hasCar){
	    console.log("Go buy a car");
    } else {
	    console.log("Enjoy driving");
    }
} else {
    console.log("Not able to get a driver licence");
}
```

You can check 2 or more conditions together:
```
if(age>=18 && hasCar){
	statement
}
```
##### else if
When the first condition fails, you may need to check another condition as well, and then use `else` at the end:
```js
if(age>=18 && hasCar){
```

##### Switch case
The other method we mentioned above is `switch case`. This helps us to check multiple `if else` like statements:
```js
const option="A";

switch(option){
	case "A":
		console.log("Option A");
		break;
		
	case "B":
		console.log("Option B");
		break;
		
	case "C":
		console.log("Option C");
		break;
		
	default:
		console.log("No option");
}
```
