First of all you need to have the node.js installed.
Next.js has some versions that the newest ones added so many features that make high differences with the previous ones.
##### Next.js installation
Remember to use the stable versions, the newest ones may come with some unfixed bugs or etc.

We will learn next js using two was, page routers and app routers. We will discuss about them later just so you know now page is simpler, we'll learn about our CSR and SSR here at first.

Now let's install it:
```bash
npx create-next-app@latest
```
We will use version 14 here:
```bash
npx create-next-app@14.2.18
```
Now it will show some questions:
1. Choose your project name(with no capital letters)
2. Select yes for Ts install
3. Yes for Eslint as well
4. You can choose whether you want to install tailwind or not.
5. Then it will ask if you want to save all your files in src folder. Yes or no is up to you
6. Then it will ask about if you want to use App router, here we want to work with page first.
7. Finally, choose no for the import alias. I don't even know what that is.
You'll see that it has installed: react, react-dom and next. These are core packages.
Then there's some dev dependencies.
##### Next js project folder explained
The main folder is called pages. Here we put our designed pages.
React router dom is not needed in next js, it has it's own routing system.

Inside the pages folder, there's the api folder, here we put the api s we want to use.
We don't need it now, so feel free to delete it for now if you don't need it.

There's the fonts folder as well.

**Running the project:**
To run the project, in the terminal you can use:
```bash
npm run dev
```
After running, copy the local host address it gives you then paste it inside the browser.

Everything you see for the first time are used in the index.tsx file. We will talk about the other 2 files later.

Public has the assets, images, fav icons and etc.

In styles folder we have css files.

Next.config.mjs has some configs.

Then the package.json.

We have tsconfig to compile our Ts files the way we want.
##### Differences with react
One of the differences with react is that it no longer has an HTML file(which was `index.html` in react). The reason is that the routing system of next js is file based, which considers the files we use in pages folder. It regenerates them.

The other difference is that when you run your project, you can right click and then choose view page source, here it will show the html that is gotten from the server, it's ready and loaded before.
They are pre-generated.

Doing the same in a react project, you only see a div.
