Let's talk about how routing works in Next js.

In your pages folder:

index:
```tsx
export default function Home() {
  return (
    <h1>Home page</h1>
  );
}
```
For example this is our homepage.

Now create a file called products inside the pages folder:
```tsx
export default function Products(){
    return(
        <div>
            <h1>Products</h1>
            <ul>
                <li>Laptops</li>
                <li>Mobiles</li>
                <li>Gaming consoles</li>
            </ul>
        </div>
    )
}
```
In order to route to our Products page, just simply type `/Products` inside the address bar of the browser.
Doing it wrong will show an error page which is designed with Nextjs. It helps to prevent the site from crashing.

*Note:* If you want to put it inside a new folder called the same name, just change your file's name to index. And use the previous name for the folder. You can see that you don't need to choose the route address in the browser.

*Note:* Your start point and main file of the project is the index.tsx file.
