Sometimes we don't want to use the link tags, we want a function's result to navigate us,
generally we want to route with programmatic navigation:

index:
```tsx
import { useRouter } from "next/router";
export default function Home() {
  const router=useRouter();
  return (
    <div>
      <h1>Home page</h1>
      <button onClick={()=>{
        //rout to about page
        router.push("/about");
      }}>Go to about page</button>
    </div>
  );
}
```
Inside the push method, use the route address.
