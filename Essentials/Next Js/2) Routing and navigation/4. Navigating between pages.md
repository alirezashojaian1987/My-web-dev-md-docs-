##### Using `<a>` tag
The first way is to use `<a></a>` tag. Just put the route address inside the `href` attribute.
We talked about the SPA and react supporting it.
Nextjs supports SPA but not completely. It has some multipage design as well bit it also isn't a fully multipage application, it's something between both of them.

If you check the network tab in the inspect of the browser, when the `a` link is pressed, one quick refresh occurs and the files get downloaded again. We pretty much covered it in previous sessions.
##### Link
You can use it to keep the SPA and the pre-generation matter of the nextjs by using the `Link` tag for routing.
To use it, we need to import it:
```tsx
import Link from "next/link";

<Link href="/Products">Go to products page</Link>
```
When using it, the re-download of the pages will no longer occur.

If you hover on the tag on vs-code you can see it's an `<a>` tag behind the scene with one big difference. The first thing the link tag does on the `a` tag is to prevent it from sending request to the server. The next thing it does is to pre-fetch the data of the page you are trying to navigate.
##### Nested routing
If you add another file inside the folder, beside the folder name address on the browser, you need to type that file's name as well.
It will be s.th like this in your folder:
Products:
1. index.tsx
2. New_products.tsx
Their routes in browser:
`localhost:3000/Products` for Products page(index.tsx)
`localhost:3000/Products/New_products` for new products page.

You can use folders as well inside the folder.
`/Products/ProductDetails`
