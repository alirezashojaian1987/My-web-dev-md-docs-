Let's talk about dynamic routing, you want to give a page a custom route address. 
##### How to use dynamic routing
When using page router in next:
In your page's folder(here is Products):
create a file in this folder with this format:
`[product_id].tsx` We can use any name we want but it should be inside the brackets.
```tsx
export default function ProductDetail(){
    return(
        <div>Product details</div>
    )
}
```
To see it on the browser, put any name or number you want after the `/Products/`
It will show you the page.

Now how to give the dynamic routing. For example when we type iphone, it show it to us:
```tsx
import { useRouter } from "next/router";
  
export default function ProductDetail(){
    const router=useRouter();
    const productId=router.query.productId;
    return(
        <div>Product details{productId}</div>
    )
}
```
`useRouter` has some methods. We'll discuss about them later.
The name should be the same name of the file's name we put inside the brackets.
