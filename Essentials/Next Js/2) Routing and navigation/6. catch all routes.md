Sometimes we want to handle some routes in one component.
For example with this structure:
`our_site/blog/tech/programming/Js`
We want to handle these in one file.

Create a folder called Blog inside the pages folder.
Now inside it create a file called `[blogId].tsx`
```tsx
import { useRouter } from "next/router";
  
export default function Blog(){
    const router=useRouter();
    const param=router.query.blogId;
    return(
        <div>
            <h1>Blog Post {param}</h1>
        </div>
    )
}
```
Now we want to handle the matter mentioned above.
We don't want to create folders inside the Blog folder with files inside them. We want to handle them all here.

In order to do so, we use the catch-all routers method.

Rename your file to this:
`[...slug].tsx` The name can be anything, it's common to use slug.
Now inside the code:
```tsx
import { useRouter } from "next/router";
  
export default function Blog(){
    const router=useRouter();
    console.log(router.query);
    const param="";
    return(
        <div>
            <h1>Blog Post {param}</h1>
        </div>
    )
}
```
Now if you put this on the browser:`http://localhost:3000/Blog/tech/programming/Js` and then open the console, you can see there's an array called slug, with three values inside it:
```
slug: Array(3)
0: "tech"
1: "programming"
2: "Js"
```
They are sorted with indexes.
Afterwards, any route you add, Nextjs considers it as a new dynamic route.
##### Main page for the catch all routes
So we talked about how to use the dynamic routing, but now what about the blog page itself, the browser shows only the dynamic routes after the `Blog/` but not `/Blog` itself.
There are two ways to handle it, first one is to create an `index.tsx` file but it is not recommended since we want to have our dynamic routing.

The best way is to rename your file name to this:
`[[...slug]]`.
