Now that we learnt more about page router and rendering types, let's dive into the **App router**. 
It was introduced in v.13 .
The differences are the folder structures and some new features that we'll mention.
##### Installation
```bash
create-next-app@14.2.20
```
Choose a name.
Yes for Ts, EsLint, Tailwind css.
You can choose whether you want the src directory or not. Here we don't need it.

Choose yes for app router. And no for the import alias.
##### The differences
First thing you see is a folder called **app**.
There are 4 files inside it. page and layout tsx files. An icon file, and Global.css file.

The first difference is that we are seeing page.tsx instead of index. You can create folders like components inside the app folder, it won't consider it page.

The files are considered as pages, that have the page name. If there is a file inside a folder called `page.tsx`, Next will consider it as a page and the route will be the folder name. 

Any other name will be considered component and etc.
