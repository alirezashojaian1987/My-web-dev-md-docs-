As we mentioned earlier, page name for a file is reserved, so you can't have a path called page.

The other file is **layout** name. You can only use one in the root of the project, but many others inside folders.

The layout file you see in the app folder, has a body tag inside it and renders the children components inside it.

The global.css file is used in it as well. 

**Icon** file name is also reserved for project.

**Fonts** folder can be outside of the app folder. We suggest that you create a folder called **assets** and put the fonts folder and others alike inside it. 
##### Pages routing
Now when creating a folder and a page file inside it, you can see it's route inside the browser.
And if searching for a not defined page, you'll see the not found page.

One of the interesting things inside App router way, is you can define a file called:
`not-found.tsx` with the exact name.
It will generate a page, when searching for a not existing page.
##### Dynamic routing
Now if you want to have pages with for example ids, you can use this folder structure:
```
app/
    blog/
        page.tsx
	    [blogId]/
		    page.tsx
```
The route path will be: `/blog/1234`

Now if you want nested route just like we had in page router approach, name your inner file:`[...blog]` which is like catch all routes method.
