##### Navigation in app router
You are putting a nav bar with nav links in the layout file(it's a server comp). When you open the browser, you can see 2 errors, one saying that you should import the `useRouter` from `next/navigation` instead of previous router, which was for page router method.

When you import it, you can see the methods are different(the push is the same).

The other error shows that we cannot use the `useRouter` inside a server comp. These hooks are for client comps.

You need to type the `use client` in the nav links component. Then you can use `usePathName`.
