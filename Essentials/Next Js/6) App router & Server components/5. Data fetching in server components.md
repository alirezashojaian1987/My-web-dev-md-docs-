Now that we are in a server comp and not a client, you can simply use the `fetch` with an address in the tsx file. 
Just remember that to put `async` behind the exported function.
Then `await` and etc.
```tsx
export default async function Home(){
	const response=fetch("https://api");
	
	const result=await response.json();
	console.log(result);
	//...
}
```
You can see the result inside the terminal.

The great thing about this is that the datas are received and rendered in the server first, you can also see the network tab in inspect mode. You can see that there are ready datas.
##### Some tips and notes
The function in the code above executes only one time, and then caches the data. Whenever you refresh, you get new datas but be careful, it's because you are in **development env**.

So if you build your project at some point, all datas will remain the same as before.

In order to update the datas, we can use the revalidate method but a little bit different:
```tsx
export default async function Home(){
	const response=fetch("https://api", {next:{revalidate:60}});
	
	const result=await response.json();
	console.log(result);
	//...
}
```
The code above, will update the datas every 60 secs. It's actually like the **ISR** but in a server comp

And if you want no cache at all:
```tsx
export default async function Home(){
	const response=fetch("https://api", {cache:"no-store"});
	
	const result=await response.json();
	console.log(result);
	//...
}
```
Now our component is a dynamic server comp.

Another tip is that you can also put all your fetch part inside a different function.
