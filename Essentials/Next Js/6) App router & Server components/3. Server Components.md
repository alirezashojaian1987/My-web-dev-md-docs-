##### What is a server component
First of all, server component is only used in app router approach, not page router.
It's a component that renders inside the server first, and then it will be sent. 

We used all the ssr and ssg and etc in page router. With the get static or other functions as well. These were all in the page layer. 

We also mentioned earlier that when rendering a page, we can decide whether it would be client component or server side. 

A server component is a page that is created on multiple components. It can be a group or client comps and server comps. 
*!Note:* You can't have server comps inside a client side page. 

In short, it's a page that is rendered on server first. Then it's sent for the client.
##### Why should we use Server comps
One of the reasons is that there are some pages which have datas that needs to be downloaded.
The data is in the component, it's better to be retrieved in back-end first than the front. Because we get a lower sized Js file. So some datas which are rendered in server, are sent ready.

The other reason is security. If the data you're using in the comp, is a secret data and it's not needed in the front-end or client side, it should be in back-end side.

*!Note:* Every work that needs user interaction, cannot be accomplished by server comp. Because there are event listeners, they exist in DOM. Also you can't use any state, side effects, web api like local storage and etc. 

This is only used in sending datas or generating static contents. You can also divide the component into a server comp part and client part.

*Note:* Every page in app router, are server comp by default. Page router has it's own functions (for server and etc.).
You can check it by simply putting a console log. You can see there are no messages in browser console.
##### How to define a page server or a client comp
You can also put a button with an event, you can see an error inside the browser which says that you need to convert this page into a client comp.
To do so, you need to put this code in the first line:
```tsx
"use client";
```

To define the page a server comp, you can define the `use server` in the first line, but there's no need for that, since it is by default.
