One of the other features that NextJs gives us is Image component.
It has some great features and optimizations.
As you may know, image is actually not easy to handle.

The size of it is one matter so it may result in a bit slower rendering.
##### Rendering first image with NextJs Image
When checking Next documents, you can see that there are 2 image docs, one saying Image itself and one saying Image(Legacy). 
The second one is for the versions before NextJs v.13 cause the image component was re-factored.

The new one is easier to use.
##### How to use
```tsx
import Image from "next/image";

export default function Home(){
  return (
    <div>
      <h2>NextJs Image component</h2>
      <Image src="/test.jpg" alt="test"/>
    </div>
  );
}
```
You need to import the Image from Next.
When using Image tag, first, you need to give it the image source. If you already imported your images inside the public folder, next will automatically find it and use it(that's why you can see there's no full directory path in the code above). But feel free to use other folders for images as well. 

Then you need to use the alt attribute. 
When running on server, an error will appear, telling you to use the required attributes which are width and height.
```tsx
import Image from "next/image";

export default function Home(){
  return (
    <div>
      <h2>NextJs Image component</h2>
      <Image src="/test.jpg" alt="test" width={1000} height={400}/>
    </div>
  );
}
```
You need to use number values for both attributes.
##### Differences between Image and `img` in HTML
if you use the image with the `img` tag with the same width and height. Open the inspect and go to network tab, when pressing on the second image, you can see it's real width and height and not the ones we defined for it. 
On the other hand, the width and height we set for the Image, will remain the same. Next sends it re-sized.
The second difference is that NextJs turns our pic's type to .webp with lower size.
