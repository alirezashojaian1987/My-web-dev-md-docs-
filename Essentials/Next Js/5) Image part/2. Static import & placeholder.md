You can use other features of the `<Image>` tag of the NextJs to help you with a better SEO.
```tsx
import Image from "next/image";

export default function Home(){
  return (
    <div>
      <h2>NextJs Image component</h2>
      <Image
        src="/test.jpg"
        alt="test"
        width={1000}
        height={400}
        placeholder="blur"
      />
    </div>
  );
}
```
The `placeholder="blur"` helps to generate the blur form of the image first, when rendering for the first time. So user can have a clear picture of the page.

*!Note:* But here's the catch, when you run a similar code like above, you run into error. Placeholder attribute only works with the static import of the image. Like: `import pic_name from "./path"`
 Then: `src={pic_name}`.
 
 So if you're not using the static import, you can use `blurDataURl` attribute instead, where you pass your image's path url to it.
 
##### other tips
 Width and height attributes, can be overridden with css styling but the picture will be rendered with the width and height attributes.
In background, Next creates multiple images with different qualities, and will return them based on the size we defined for them.
