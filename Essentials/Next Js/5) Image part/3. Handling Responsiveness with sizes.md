It's important to take care of the responsive matter for our image as well.
We know we can use **media query** in our code. But we also learnt that the sizes we defined cannot be differed with CSS styling dynamically.

When refreshing the page, image still downloads with the defined sizes. Even though the image is shown in our webpage responsive due to the media query we used.
##### Sizes attribute
In order to solve the problems mentioned above, we can use sizes attribute.
It's like media query.
```tsx
sizes="(max-width:800px) 680px, 1080px"
```
If you pay attention, you can see it's like ternary condition.
