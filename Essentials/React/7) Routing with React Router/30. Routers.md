Imagine that you are in a website and there's multiple links to different sections of that site, when using html and js alone, we learnt that when we send a request, every html and css files will be downloaded. 

In React which we know that it's a single page application, we only have one html file, including contents that we request for, when needed in order to generate. 
For this matter comes routing which is pretty important handling it in **React** projects. 

We need the React router package so it can help us switch between pages without sending requests for files or whatsoever...

##### Installing React Router
To install React router package, use this command:
```bash
npm i react-router-dom@latest
```
*Note:* Type version after the @

##### Using Routers
There are to methods in order to use routers. 
The old method is using **Browser router**
###### Browser router
To use it, first we need to import it in the **main.jsx** file.
```jsx
import { BrowserRouter } from "react-router-dom";
```
Then we can use it as a wrapper in our main code:
```jsx
import { StrictMode } from 'react'
import { createRoot } from 'react-dom/client'
import App from './App.jsx'
import "./index.scss";
import { BrowserRouter } from "react-router-dom";
  
createRoot(document.getElementById('root')).render(
  <StrictMode>
    <BrowserRouter>
      <App />
    </BrowserRouter>
  </StrictMode>
)
```

Now we can go to `App.jsx` file and define our different routes with their own contents.

First we need to import these:
```jsx
import { Routes,Route } from "react-router-dom";
```

Then we need to use the Route elements:
```jsx
<Routes>
	<Route path="/" element={}/>
</Routes>
```
As you can see there are some arguments in our **Route** tag. Path is obvious, the element is where we define our router.
It's better that you make a folder named **Pages** in your project, then make any page files with their own stylings. Finally we can use them in our router.

```jsx
import styles from "./App.module.scss";
import Header from "./components/Header/Header.jsx";
import { Routes,Route } from "react-router-dom";
import Homepage from "./Pages/Homepage/Homepage.jsx";
import Shop from "./Pages/Shop/Shop.jsx";

export default function App(){
  return(
    <div className={styles.appContainer}>
      <Header/>
  
      <Routes>
        <Route path="/" element={<Homepage />}/>
        <Route path="/Shop" element={<Shop/>} />
      </Routes>
  
    </div>
  )
}
```
Here's an example of how we define our routers.
1. we create a folder for different pages
2. Then we create files and style them and...
3. Then we import them in the `App.jsx` file
4. Afterwards we use the `Routes` element as a wrapper
5. And eventually we use the `Route` element to give the page files paths.

On the example above if you type this on the search bar of the browser:
```bash
http://localhost:5173/Shop
```
You switch to shop page. 

**How to route between our pages:**
We need to use the methods that are for router
*!Note:* Do not use `<a> tags` for routing. It's because when pressing on it, you're still sending requests which we're trying to avoid the whole time.

We can use a default tag in the router called `Link`
It's similar to the `<a>` tag.

`App.jsx`
```jsx
import Homepage from "./Pages/Homepage/Homepage.jsx";
import Shop from "./Pages/Shop/Shop.jsx";
import { Link } from "react-router-dom";
  
export default function App(){
  return(
    <div className={styles.appContainer}>
      <Header/>
      <Link to="/Shop">Go to Shop page</Link>
      <Routes>
        <Route path="/" element={<Homepage />}/>
        <Route path="/Shop" element={<Shop/>} />
      </Routes>
  
    </div>
  )
}
```

`Shop.jsx`
```jsx
import { Link } from "react-router-dom"
  
export default function Shop(){
    return(
        <div>
            <h2>Shop page</h2>
            <Link to="/" >Go back to Homepage</Link>
        </div>
    )
}
```

###### Create Browser Router and Nested router
The next method of using routers is using the `createBrowserRouter`
The routes will be like a array of objects, which is cleaner and more organized.

```jsx
import { StrictMode } from 'react'
import { createRoot } from 'react-dom/client'
import App from './App.jsx'
import "./index.scss";
import { createBrowserRouter,RouterProvider } from "react-router-dom";
import Homepage from './Pages/Homepage/Homepage.jsx';
import Shop from './Pages/Shop/Shop.jsx';
  
const router=createBrowserRouter([
  {
    path:"/",
    element:<Homepage/>,
  },
  
  {
    path:"/Shop",
    element:<Shop/>,
  }
])
  
createRoot(document.getElementById('root')).render(
  <StrictMode>
    <RouterProvider router={router}/>
  </StrictMode>
)
```
As you can see above, there are some major differences. First thing is that we made our routes in the main file.
The second difference is that we now have a router element that contains multiple routes.
Third one is that we use `RouterProvider` tag instead of the `App` tag.

The problem is now that we are using router provider instead of the app tag, the contents are now missing. If using the App tag in one of the routes, the page renders but there comes another problem, the header we defined will not be shown when routing between pages.

So the solution is to create a shared component to render the header for all pages.

Now let's get to it.
```jsx
import { StrictMode } from 'react'
import { createRoot } from 'react-dom/client'
import App from './App.jsx'
import "./index.scss";
import { createBrowserRouter,RouterProvider } from "react-router-dom";
import Homepage from './Pages/Homepage/Homepage.jsx';
import Shop from './Pages/Shop/Shop.jsx';
import Layout from "./components/Layout/index.jsx";
  
const router=createBrowserRouter([
  {
    path:"/",
    element:<Layout/>,
    children:[
      {
        path:"/",
        element:<Homepage/>,
      },
  
      {
        path:"/Shop",
        element:<Shop/>,
      }
    ]
  }
])
  
createRoot(document.getElementById('root')).render(
  <StrictMode>
    <RouterProvider router={router}/>
  </StrictMode>
)
```

Now create a folder named layout with the same name file in it. It will help us to include the same contents or styles and etc. of the pages. And the other pages will be rendered as children. So we use Outlet here. 

What outlet here does is that now that you are using layout, the layout will be your main general component and the others will be as the sub sets of this component. That's why we use outlet.
```jsx
import styles from "./Layout.module.scss";
import Header from "../Header/Header";
import { Outlet } from "react-router-dom";
export default function index(){
    return(
        <div className={styles.layout}>
            <Header/>
            <Outlet/>
        </div>
    )
}
```

One of the things you can do with the nested router, is to declare your main page. With using `index:true` for the page you want.
```jsx
const router=createBrowserRouter([
  {
    path:"/",
    element:<Layout/>,
    children:[
      {
        index:true,
        element:<Homepage/>,
      },
  
      {
        path:"/Shop",
        element:<Shop/>,
      }
    ]
  }
])
```

You can also define that which router belongs to who.
