Now that we learnt s.th from routers, let's talk about how to actually realize which route we are currently on, and how to switch between routes better.
Using `Link` tag is an old way, but now we can use `Navlink` with some better features.
First, we need to import it:
```jsx
import styles from "./Navbar.module.scss";
import { NavLink } from "react-router-dom";
export default function Navbar(){
    return(
        <div className={styles.headerContainer}>
            <h1>My shop</h1>
            <nav>
                <ul className={styles.navItems}>
                    <li>
                        <NavLink to="/">Home</NavLink>
                    </li>

                    <li>
                        <NavLink to="/Shop">Shop</NavLink>
                    </li>

                    <li>
                        <NavLink to="About_us">About us</NavLink>
                    </li>

                    <li>
                        <NavLink to="Login">Login</NavLink>
                    </li>
                </ul>
            </nav>
        </div>
    )
}
```
One of the good features of `NavLinks` is that if you open dev tools in the browser, and then hover your mouse on the links, you can see that they get a class name called active, so this property can actually help us to style it better, for example in a way to understand which page is currently active.

Now we need to style it.

The best thing we can do is using class name with a function inside it, and then style it with tailwind or ...
```jsx
import { NavLink } from "react-router-dom";
import styles from "./Navbar.module.scss";

export default function Navbar(){
    return(
        <div className={styles.NavbarContainer}>
            <h1>My shop</h1>
            <nav>
                <ul className={styles.navItems}>
                    <li>
                        <NavLink to="/" className={({isActive})=>isActive ? "font-bold text-black" : "text-gray-500"}>Home</NavLink>
                    </li>
                    
                    <li>
                        <NavLink to="/Shop" className={({isActive})=>isActive ? "font-bold text-black" : "text-gray-500"}>Shop</NavLink>
                    </li>

                    <li>
                        <NavLink to="/About_us" className={({isActive})=>isActive ? "font-bold text-black" : "text-gray-500"}>About us</NavLink>
                    </li>

                    <li>
                        <NavLink to="/Login" className={({isActive})=>isActive ? "font-bold text-black" : "text-gray-500"}>Login</NavLink>
                    </li>
                </ul>
            </nav>
        </div>
    )
}
```
