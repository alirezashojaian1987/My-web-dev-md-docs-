Now after handling routes on the navbar and the pages, we now want to go for the category pages we defined in the shop project.

Now it's actually better to always separate the routes and the main page and put them in an specific page called routes for example:
```jsx
import { createBrowserRouter } from "react-router-dom";

import Homepage from "./Pages/Home/Homepage";
import Shop from "./Pages/Shop/Shop";
import AboutUs from "./Pages/AboutUs/AboutUs";
import Login from "./Pages/Login/Login";
import Layout from './components/Layout/Layout';

export const router=createBrowserRouter([
  {
    path:"/",
    element:<Layout/>,
    children:[
      {
        index:true,
        element:<Homepage/>,
      },

      {
        path:"Shop",
        element:<Shop/>
      },

      {
        path:"About_us",
        element:<AboutUs/>
      },

      {
        path:"Login",
        element:<Login/>
      },
    ]
  },
]);
```

But hey, it's not really appropriate to create so many page files, specially that these kinds of websites may contain so much more contents. So it's better to put them all in one page and with some settings we can route between them dynamically instead of having so many files for each item in a category or list.

Just create a component and give it some dynamic values. It's used by a router method called parameters.

So first create a jsx file called Collection
(No need for contents in it for now)

Then in the `routes.jsx`
```jsx
import { createBrowserRouter } from "react-router-dom";

import Homepage from "../Pages/Home/Homepage";
import Shop from "../Pages/Shop/Shop";
import AboutUs from "../Pages/AboutUs/AboutUs";
import Login from "../Pages/Login/Login";
import Layout from '../components/Layout/Layout';
import Collection from "../Pages/Collection/Collection";

export const router=createBrowserRouter([
  {
    path:"/",
    element:<Layout/>,
    children:[
      {
        index:true,
        element:<Homepage/>,
      },

      {
        path:"Shop",
        element:<Shop/>
      },

      {
        path:"About_us",
        element:<AboutUs/>
      },

      {
        path:"Collection/:category",
        element:<Collection/>
      },

    ]
  },
]);
```
So now you can type on the search bar beside the address: 
`http://localhost:5173/Collection/test`
*Note:* We can't use collection alone because we defined a parameter for it.

Now to access the parameters.
One of the hooks in react that can help us to realize which hook we're currently on and what are it's parameters is the `useLocation`

Open the collection file:
```jsx
// import styles from "./Collection.module.scss";

import { useLocation } from "react-router-dom"

export default function Collection(){

    const location=useLocation();
    console.log(location);

    return(
        <div>Collection</div>
    )
}
```
Now open the browser console and you can see that there's an object with path and some other things.

Now we need to get the parameters and that can be possible with `useParams` hook.
```jsx
// import styles from "./Collection.module.scss";

import { useLocation, useParams } from "react-router-dom"

export default function Collection(){

    const location=useLocation();
    console.log(location);

    const params=useParams();
    console.log(params);

    return(
        <div>Collection of {params.category}</div>
    )
}
```
Use params will help us to realize which parameter is currently active.

##### UseNavigate hook
Now to navigate between the parameters to render them we can use a hook called useNavigate.
In the menu item file, we want to define a function to help us switch to the category we press on it.
```jsx
import styles from "./Menu_item.module.scss";
import {useNavigate} from "react-router-dom"

export default function Menu_item({title,subtitle,imageUrl}){

    const navigate=useNavigate();

    return(
        <div 
            className={styles.wrapper}
            onClick={()=>navigate(`/Collection/${title}`)}
        >
            
            <div 
                className={styles.background_image} 
                style={{
                backgroundImage:`url(${imageUrl})`
            }}>

            </div>
            <div className={styles.content}>
                <h3>{title}</h3>
                <p>{subtitle}</p>
            </div>
        </div>
    )
}
```
You can navigate now.

Homepage:
```jsx
import styles from "./Homepage.module.scss";
import { categories } from "../../constants/mock";
import Menu_item from "../../components/MenuItem/Menu_item";
import {useNavigate} from "react-router-dom";

export default function Homepage(){
    const navigate=useNavigate();
    const handleClick=(title)=>navigate(`/Collection/${title}`);
    return(
        <div className={styles.menuContainer}>
            {categories.map((item)=>(
                <Menu_item title={item.title} key={item.id} imageUrl={item.image} onClick={()=>handleClick(item.title)}/>
            ))}
        </div>
    )
}
```
