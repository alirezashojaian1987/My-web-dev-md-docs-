Let's learn using it in basic JS file first.
##### Installing redux
In terminal, run this command:
```bash
npm i redux
```
##### Redux basic
```js
import { createStore } from "redux";

const store=createStore();
```
When using the create store, it will show a line on it, this method is actually deprecated and is being replaced with redux toolkit methods. But the base is still the same.

`createStore()` gets one arg which is the reducer we need to create.
```js
import { createStore } from "redux";

const initialVal={
    counter:0,
}
  
const reducer=(state=initialVal,action)=>{ //state must always be defined with an initial value
    //some operations
    return state;
}
  
const store=createStore();
```
##### How to change the states
```js
import { createStore } from "redux";
  
const initialVal={
    counter:0,
}
  
const INCREASE="increase";
const DECREASE="decrease";
  
const reducer=(state=initialVal,action)=>{
    if(action.type===INCREASE){
        return{
            counter:state.counter+1,
        };
    };
    if(action.type===DECREASE){
        return{
            counter:state.counter-1,
        };
    };
  
    return state;
}
  
const store=createStore(reducer);

// For example in a page
store.dispatch({type:INCREASE})
```
We created an store with a reducer in it.
In order to send a change from the UI to the reducer to make it, we need to dispatch the action we need.
```js

    counter:0,
}
  
const INCREASE="increase";

    return state;

```
The action is actually an object. We can pass payload as well.
You can define your own actions as well:
```js
import { createStore } from "redux";
  
const initialVal={
    counter:0,
}
  
const INCREASE="increase";
const DECREASE="decrease";

const increaseCounter=()=>({type:INCREASE});
const decreaseCounter=()=>({type:DECREASE});
  
const reducer=(state=initialVal,action)=>{
    if(action.type===INCREASE){
        return{
            counter:state.counter+1,
        };
    };
    if(action.type===DECREASE){
        return{
            counter:state.counter-1,
        };
    };
  
    return state;
}
  
const store=createStore(reducer);

// For example in a page
store.dispatch(increaseCounter());
```
##### When do the components notice the store change
```js
import { createStore } from "redux";
  
const initialVal={
    counter:0,
}
  
const INCREASE="increase";
const DECREASE="decrease";

const increaseCounter=()=>({type:INCREASE});
const decreaseCounter=()=>({type:DECREASE});
  
const reducer=(state=initialVal,action)=>{
    if(action.type===INCREASE){
        return{
            counter:state.counter+1,
        };
    };
    if(action.type===DECREASE){
        return{
            counter:state.counter-1,
        };
    };
  
    return state;
}
  
const store=createStore(reducer);

// For example in a page
store.dispatch(increaseCounter());

//notice store changes
store.subscribe(()=>{
	//some logic
	store.getState();// returns the final value of state
});
```
