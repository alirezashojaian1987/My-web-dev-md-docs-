When an action triggers, you can apply some logics and states on it before it gets to the reducers.
More control on the action can be possible with this.
##### What is Middleware
It provides a third party extension point between dispatching an action, and the moment it reaches the reducer. For example you can use it in logging, because in real development area, you can't access the local servers dev tools.
Or crash reporting, or sending requests to an asynchronous API, routing and more.
