Redux toolkit has redux core inside it, and some more packages to create a better redux app and helps you use redux easier.
##### Installation
```bash
npm install @reduxjs/toolkit
```
##### How to work with the redux toolkit
```js
import { createSlice } from "@reduxjs/toolkit";

const initialVal={counter:0,showCounter:true};
export const counterSlice=createSlice({
    name:"counter",
    initialState:initialVal,
    reducers:{
        increaseCount(state){
            state.counter++;
        },
        decreaseCount(state){
            state.counter--;
        },
        resetCount(state){
            state.counter=0;
        },
        toggleCount(state){
            state.showCounter=!state.showCounter;
        },
        increaseRandom(state,action){
            state.counter+=action.payload;
        },
    }
});
```
*Note:* so the method `createSlice` has 3 crucial args:
1. `name`: You can use the state name you want
2. `initialState`: Is the value you set before.
3. `reducers`: Are the functions you want to use for your state updates.

*Note:* We said that mutating the state in redux will override the previous state. 
But in toolkit, there's a background layer called **Immer** which helps us to mutate the state directly without worrying about the override.
You can mutate the state as you want, the immer get's a copy of the state whenever you do any operation on the state and then it replaces the state, with the new copy.
You don't even have to worry.

Now to use our new reducer in store:
```js
import { createStore } from "redux";
import { counterSlice } from "./reducers/counterReducer";
  
export const store=createStore(counterSlice.reducer);
```
Or if you have more than one reducers:
```js
import { createStore,combineReducers } from "redux";
import { counterSlice } from "./reducers/counterReducer";
  
const reducers=combineReducers({
    counter:counterSlice.reducer,
    //for example: cart:cartSlice.reducer,
})
export const store=createStore(reducers);
```
This merges all reducers and now you can use all of them.
##### Configure store
Create store method as mentioned before, is deprecated and no longer is used. The suggestion is configure store:
```js
import { counterSlice } from "./reducers/counterReducer";
import { configureStore } from "@reduxjs/toolkit";

const reducers=combineReducers({
    counter:counterSlice.reducer,
    //for example: cart:cartSlice.reducer,
})
export const store=configureStore(reducers);
```
Because we want to delete redux, we can use another method for the combine reducers.
The `configureStore` returns object. So:
```js
import { counterSlice } from "./reducers/counterReducer";
import { configureStore } from "@reduxjs/toolkit";

export const store=configureStore({
	reducer:{
		counter:counterSlice.reducer,
	},
});
```
##### Actions in create slice
Now that we use the create slice, it also helps us with declaring actions, so we no longer need to create an actions page.
CounterReducer.js
```js
import { createSlice } from "@reduxjs/toolkit";
  
const initialVal={counter:0,showCounter:true};
  
export const counterSlice=createSlice({
    name:"counter",
    initialState:initialVal,
    reducers:{
        increase(state){
            state.counter++;
        },
        decrease(state){
            state.counter--;
        },
        reset(state){
            state.counter=0;
        },
        toggle(state){
            state.showCounter=!state.showCounter;
        },
        increaseRandom(state,action){
            state.counter+=action.payload;
        },
    }
});
  
export const counterActions=counterSlice.actions;
```
The slice we created also returns a method called actions, it creates actions for each reducer we defined. Makes our work much easier.
Store.js
```js
import { counterSlice } from "./reducers/counterReducer";
import { configureStore } from "@reduxjs/toolkit";

  
export const store=configureStore({
    reducer:{
        counter:counterSlice.reducer,
    },
});
```
Now in App.jsx
```jsx
import Button from "./components/Button/Button";
import { useState,useReducer } from "react";
import { useDispatch, useSelector } from "react-redux";
import { counterActions } from "./redux/reducers/counterReducer";

export default function App(){
  const dispatch=useDispatch();
  const {counter,showCounter}=useSelector((state)=>state.counter);
  return(
    <div className="w-full h-screen bg-white flex flex-col items-center justify-center gap-8 text-md">
      {
        showCounter?(
        <>
          <p>Counter: {counter}</p>
          <div className="flex gap-8">
            <Button onClick={()=>dispatch(counterActions.increase())}>Increase</Button>
            <Button onClick={()=>dispatch(counterActions.reset())}>Reset</Button>
            <Button onClick={()=>dispatch(counterActions.decrease())}>Decrease</Button>
            <Button onClick={()=>dispatch(counterActions.increaseRandom(Math.round(Math.random()*10)))}>Increase by random amount</Button>
          </div>
        </>
      ):null}
      
      <Button variant="secondary" onClick={()=>dispatch(counterActions.toggle())}>Toggle count</Button>
    </div>
  )
}
```
Now you can safely remove the actions folder and files in it. Also remove redux from the `package.json` file and then run the command `npm i`.
