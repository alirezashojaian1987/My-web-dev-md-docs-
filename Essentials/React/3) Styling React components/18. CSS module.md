As mentioned before, BEM really isn't a proper way to name our elements classes or ids.

Good thing about the css modules is that it has scopes unlike the css vanilla which is always global.

To create a css module file:
`name.module.css`
The module and css postfixes are necessary.

```css
.list_item{
    background-color: transparent;
    border-radius: 6px;
    padding:4px 5px;
}
  
.sel_item{
    background-color: greenyellow;
}
  
.welcome_msg{
    padding:12px 8px;
    font-size: 18px;
    font-weight: 500;
}
```

```jsx
import { useState } from "react";
import styles from "../styles/list.module.css"
  
const List=(props,onClick)=>{
    const [sel_item,setSel_item]=useState(0);
    const handle_click=(index,item)=>{
        setSel_item(index);
        onClick(item);
    }
    return(
        <>
            <h1>Hello my niggas</h1>
            <label className={styles.welcome_msg}>Best high tech companies</label>
            <ul>
                {props.items?.length?(
                    props.items.map((item,index)=>(
                        <li
                            onClick={()=>handle_click(index)}
                            key={item}
                            className={`${styles.list_item} ${sel_item===index? styles.sel_item:""}`}
                        >
                            {item}-{index}
                        </li>
                    ))
                ):(
                    <div>There is no item</div>
                )}
            </ul>
        </>
    );
};
  
export default List;
```
you can name other things for styles object as well.

The reason css module is better is that when you go and inspect, your defined class name is different due containing an id in it.
