As you know, it matters that our code file doesn't contain many codes. So let's say you want to make a project, do you think the App.css and index.css files can handle all of it? The answer obviously is yes but is it beneficial? No

When you create your react env with vite, there are those two css files. App.css selects all it's children in the App.jsx

Best thing to do is to create each file's css for itself, near it.

So now remove all your styles for the list. Create a list.css and use them there.

Remember, naming in css files in you projects highly matters cause one wrong naming can make some conflicts with other styles, cause you know, css doesn't care about scopes.

One solution is to name things in the **BEM** way.
`blockName__element--modifire`
```css
.list__item{
    background-color: transparent;
    border-radius: 6px;
    padding:4px 5px;
}
  
.--active{
    background-color: greenyellow;
}
  
.welcome_msg{
    padding:12px 8px;
    font-size: 18px;
    font-weight: 500;
}
```

```jsx
import { useState } from "react";
import "../styles/list.css"

const List=(props,onClick)=>{
    const [sel_item,setSel_item]=useState(0);
    const handle_click=(index,item)=>{
        setSel_item(index);
        onClick(item);
    }
    return(
        <>
            <h1>Hello my niggas</h1>
            <label className="welcome_msg">Best high tech companies</label>
            <ul>
                {props.items?.length?(
                    props.items.map((item,index)=>(
                        <li
                            onClick={()=>handle_click(index)}
                            key={item}
                            className={`list__item ${sel_item===index? "--active":""}`}
                        >
                            {item}-{index}
                        </li>
                    ))
                ):(
                    <div>There is no item</div>
                )}
            </ul>
        </>
    );
};
  
export default List;
```

As you can see, BEM lowers the chances of conflicts. The downside of it is there is still a bit chance, or when you are doing projects with friends, the chance is higher.

The other problems is that it may get longer in name.
