Sass is a CSS extension that adds many features to work with. It needs a compiler for the codes to turn into css.

Sass can be done in 2 ways:
1. **SCSS**: which is mostly like css
2. **SASS**: Which is a little different, for example there's no {}. The styling are separated using dashes, spacing.
SCSS is more common due to it's readability.

##### Installation
To install it, checking the site you installed your framework from, is recommended. Here we are checking vite.
Go to it's website, then in guides section, open features.

Scroll down until you reach css and css pre-processors.
There are other commands as well, but for here we need the sass installation command:
```bash
npm add -D sass-embedded
```
Vite here acts as a compiler for our css.

Now to import and use it. 
Create a file named: `index.scss`(any name).
Open main.jsx file and type:
```jsx
import "./index.scss"
```

##### How it works?
The whole thing works like css but with some differences. First of all you can now use your nested styling, lets say you have a div with a class. The div has some inputs and buttons in it. Now without any worries about setting a class or id for them, you can just call them inside the div selector.

The other difference is that you can define and use variables.
```scss
$blue:#0d6efd;
$primary:blue;

body{
	background-color:$blue;
	//or
	background-color:$primary;
}
```

Now the best way to use our variables?
Well create a scss file just for the variables. In the other scss file use this command and you're good to go:
```scss
@import "./address and file name";
```

Not just colors, you can define font variables as well.
