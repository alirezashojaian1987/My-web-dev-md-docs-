It's a new styling tool. Don't worry, every tools base is still css, just some syntax changes.

To install, run the command:
```bash
npm install styled-components
```
Then add this to the package json file:
```json
"resolutions":{
    "styled-components":"^5"
  }
```
##### Styled component
What it does is that you can create a new tag that has some styles and...
You can use styles in your jsx files. I recommend using it on short component files.

create a Heading file in components
```jsx
import styled from "styled-components";
const Text=styled.div`
 color:black;
 font-size:24px;
 padding:8px;
 margin:12px;
 font-weight:500;
`
const Heading=({title})=>{
    return <Text>{title}</Text>;
}
  
export default Heading;
```

Now style card as well:
```jsx
import styled from "styled-components";
  
const Wrapper=styled.div`
    background-color: gray;
    border-radius: 6px;
    padding:24px;
    margin:8px 16px;
    display: flex;
    flex-direction: column;
    align-items: center;
    justify-content: center;
  
    & label{
        color:black;
        font-size:14px;
    }
  
    &:hover{
        background-color:#ccc;
    }
`;
  
const Card=({children})=>{
    return <Wrapper>{children}</Wrapper>
};
  
export default Card;
```

Always name with the 1st uppercase letter. Then styled and after the style, choose what is the base tag for it.

```jsx
import './App.css'
import List from "./components/list";
import Card from './components/Card';
import Heading from './components/Heading';
  
const companies=["Tesla","Microsoft","Sony","Apple"];
function App() {
  const handle_sel_item=(item)=>{
      console.log(item);
  }
  return (
      <div>
        <Card>
          <Heading title="React Project"/>
          <List
          items={companies}
          onClick={handle_sel_item}
          />
        </Card>
      </div>
  );
}
  
export default App
```
