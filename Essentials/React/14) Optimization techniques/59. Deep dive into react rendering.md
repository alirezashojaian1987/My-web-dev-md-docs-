Performance is an important matter in the programming world, no matter the language or environment.
In react, one of the main matters we should always be careful about is the re-rendering.

Virtual dom always change the dom with checking the state.
Whenever an state changes, a re-render occurs.
When you pass a prop from a parent to a child component, that child gets re-rendered.
If a state changes in the parent component, the children also get re-rendered as well.

So it's important where to use our logic and making our states.

For prop drilling matter we could use some tools like context or redux.

Now why we actually say to be careful about the re-render matter. 
In a react project, every pages are rendered inside one div with `root` id. And that will contain more divs inside it,
Now imagine the main file at the top tree. If it gets re-rendered, every child will as well.
Their children will get rendered twice, one for main file, one for parent, and this multiplies by 2 for the lower nodes of the tree, so the re-render matter actually follows O( n^2 ).
