Imagine you have your shop web designed.
You added a product or many ones to your cart. If you close the page, or refresh the browser, all your progress and saves will be cleared as well.

This applies for Login as well. 
In other words, the data gets reset in the browser completely.

Context, useReducer, useState,... are temporary in the browser and when refreshing happens, all of them will be initialized again.

So let's store our datas in our browsers. There are two ways, sending requests from the user to server to get the data and store it in the database.
Or using a local storage.(This is better for temporary savings).

Browser storage can be used in 2 ways:
1. Local storage
2. Session storage
Both of them are storages and they store data as **key value pairs**
The key and value are string.

The main difference between them is that in local storage you can save the datas in the browser and they don't have an expire time, which means that unless the user hasn't cleared their local storage, the data remains there.

Session storage on the other hand, keeps the data until the browser tab is open(refresh won't clear the data, only stopping server or closing the tab).

Let's use session storage first for our login. We should use it in the auth context we provided.
```jsx
import { createContext,useState } from "react";
  
export const AuthContext=createContext();
  
export default function AuthContextProvider({children}){
    const [auth,setAuth]=useState(null);
  
    return(
        <AuthContext.Provider value={{auth,setAuth}}>
            {children}
        </AuthContext.Provider>
    )
}
```
This was our auth context.

##### Using session storage
To use session storage:
```console
sessionStorage.setItem()
```
When on console, when using the code above, you can give it key as the first arg and the value for the second arg.

**Saving item on session storage:**
For example:
on the console:
```js
sessionStorage.setItem("test","100");
sessionStorage.setItem("test2","200");
```
Now on the tools, go to the application tab and open the session storage there to see your saved key values.

**Getting item from session storage:**
Now that the data is saved on your session storage, to get it, you can use the get item method. You need to use the specified key.
```js
sessionStorage.getItem("test");
//100
```

**Remove item from session storage:**
When removing, you use the key as well.
```js
sessionStorage.removeItem("test");
```
Now you can check the storage there.

**Clear:**
```js
sessionStorage.clear();
```
The whole storage get's cleared.

**Saved data**
Now if you refresh the page, you can still see that your data is in the session storage.
##### Local storage
It's just the same as session storage.
```js
localStorage.setItem(key,val);
localStorage.getItem(key);
localStorage.removeItem(key);
localStorage.clear();
```
##### Use storages on projects
It's better that you know which storage is better for which data or state.
When using the storages, we use the `useEffect` cause saving data is a side effect.
```jsx
import { createContext,useState } from "react";
  
export const AuthContext=createContext();
  
export default function AuthContextProvider({children}){
    const [auth,setAuth]=useState(null);
	
	useEffect(()=>{
		sessionStorage.setItem("authentication",JSON.stringify(auth));
	})
	 
    return(
        <AuthContext.Provider value={{auth,setAuth}}>
            {children}
        </AuthContext.Provider>
    )
}
```
As we said before, the data gets stored as string, so remember not to use your object here. 
If you use it as the value arg by mistake, in the session storage you can see it's only saved `[object Object]` and there are no values in it.

So we used the `JSON.stringify` method to turn it into a string.
When running the code above, if you refresh, the data is still not set, cause you gave the initial value null to auth.
```jsx
import { createContext,useState } from "react";
  
export const AuthContext=createContext();
  
export default function AuthContextProvider({children}){
    const [auth,setAuth]=useState(JSON.parse(sessionStorage.getItem("authentication")) || null);
	
	useEffect(()=>{
		sessionStorage.setItem("authentication",JSON.stringify(auth));
	})
	 
    return(
        <AuthContext.Provider value={{auth,setAuth}}>
            {children}
        </AuthContext.Provider>
    )
}
```
We use `JSON.parse` method to turn the string into the value type(which here is object) we needed.
If the storage is empty, it will return undefined, that's why we handled the condition to put null as the initial value if there was no key and value.
