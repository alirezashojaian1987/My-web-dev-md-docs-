As mentioned before, it's not common to use strings for our actions in reducer matter. They are commonly used as objects.

When defining them, they have 2 main key value pairs:
```jsx
action={type="",payload=""};
```
As we said earlier the names are optional but they are based on the defined meaning for it. First one is for the actions **type** and the **payload** is the value we give the reducer in order to set in our state.

```jsx
import Button from "./components/Button/Button";
import { useState,useReducer } from "react";

const tasks=[
  {id:1,task:"Learning HTML"},
  {id:2,task:"Learning CSS"},
  {id:3,task:"Learning JS"},
  {id:4,task:"Learning React"},
];

const ADD="add";
const DELETE="delete";

const taskReducer=(state=[],action)=>{
  if(action.type===ADD){
    let id=1;
    if(state.length){
      const lastIndex=state[state.length-1];
      id=lastIndex.id+1;
    }
  
    return [...state,{id,task:action.payload}];
  }

  if(action.type===DELETE){
    return state.filter(task=>task.id!==action.payload);
  }
};

export default function App(){
  const [inputValue,setInputValue]=useState("");
  const [state,dispatch]=useReducer(taskReducer,tasks);

  return(
    <div className="w-full h-[100vh] bg-white flex flex-col items-center justify-center gap-8 text-md">
      <div className="flex items-center gap-3">
        <input
          value={inputValue}
          onChange={(e)=>setInputValue(e.target.value)}
          className="border border-black h-10"
        />
  
        <Button className="w-24" variants="secondary" onClick={()=>dispatch({type:ADD,payload:inputValue})}>
          add
        </Button>
      </div>
  
      <div className="flex flex-col gap-8">
        {state?.map((item)=>(
          <div className="flex justify-between w-96 gap-3 items-center border-dashed border border-gray-600">
            <span>{item.task}</span>
            <Button className="w-24 !text-red-500" variant="secondary" onClick={()=>dispatch({type:DELETE,payload:item.id})}>
              Delete
            </Button>
          </div>
        ))}
      </div>
    </div>
  )
}
```
In the example above, we want to add and remove tasks with useReducers. 

Remember, it's better to put all your reducers or constant variables in one file and then import them to use them.
