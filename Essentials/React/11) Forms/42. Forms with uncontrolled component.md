We can use the `form` tag in case we want to create a form for pages like submission or login and... . 
There are some tools that helps us with using forms in an easier way.
```jsx
import styles from "./Login.module.scss";
import Button from "../../components/Button/Button";
import { useContext } from "react";
import {AuthContext} from "../../Context/AuthContext";
  
export default function Login(){
    return(
        <div>
            <h1>Login page</h1>
            <form>
                <label htmlFor="username">Username:</label>
                <input id="username" type="text" />
  
                <label htmlFor="password">Password</label>
                <input id="password" type="text" />
            </form>
        </div>
    )
}
```
Having this simple form. the attribute `htmlFor` in label, gets the input id, and when clicked on that label, the input will be focused.

```jsx
import styles from "./Login.module.scss";
import Button from "../../components/Button/Button";
import { useContext } from "react";
import {AuthContext} from "../../Context/AuthContext";
  
export default function Login(){
    return(
        <div className="flex flex-col w-full items-center h-screen justify-center">

            <form className="flex flex-col bg-gray-500 p-6 gap-3">
                <label htmlFor="username">Username:</label>
                <input id="username" type="text" className="bg-white" />
  
                <label htmlFor="password">Password</label>
                <input id="password" type="text" className="bg-white" />
  
                <Button className="bg-black text-white">Submit</Button>
            </form>
        </div>
    )
}
```
When pressing the submit button, if you check network tab on console, you can see that a refresh occurs, it's not because of the button, but it's actually cause of form. 

When a button is pressed in forms, a form submission happens, and happening so, the form sends a request to the server, that's why the refresh happens.

In order to prevent that, we can use this function in our form, but we should define it:
```jsx
import styles from "./Login.module.scss";
import Button from "../../components/Button/Button";
import { useContext } from "react";
import {AuthContext} from "../../Context/AuthContext";
  
export default function Login(){
    return(
        <div className="flex flex-col w-full items-center h-screen justify-center">
            <h1>Login page</h1>
            <form
                onSubmit={(event)=>{
                    event.preventDefault();
                    console.log("event",event);
                }}
                className="flex flex-col bg-gray-500 p-6 gap-3"
            >
                <label htmlFor="username">Username:</label>
                <input id="username" type="text" className="bg-white" />
  
                <label htmlFor="password">Password</label>
                <input id="password" type="text" className="bg-white" />
  
                <Button className="bg-black text-white">Submit</Button>
            </form>
        </div>
    )
}
```
Without the prevent default, whenever you enter a username and password and then submit, the form makes the refreshing happens cause of the request and... 

This function helps on preventing that.

##### How to access the input values using `useRef`
We used value attribute before. `value={}`
Now here's a new hook called `useRef`. 

It stores some value on memory and they wouldn't change on re-renders.
And `useRef` won't change the dom or cause re-render when it's data changed.
One of the other benefits of useRefs, is to access dom's values directly.

useRef should always be at the top level of component and cannot be in the `return` section.
First import it from react.
```jsx
import { useRef } from "react";

export default function Login(){
    const userInputRef=useRef(null);
    const passwdInputRef=useRef(null);
```
Now you have two references. Their initial value should always be `null` at start

Now you can give them to the inputs, using `ref={}` attribute.
```jsx
import styles from "./Login.module.scss";
import Button from "../../components/Button/Button";
import { useContext, useRef } from "react";
import {AuthContext} from "../../Context/AuthContext";
  
export default function Login(){
  
    const userInputRef=useRef(null);
    const passwdInputRef=useRef(null);
  
    return(
        <div className="flex flex-col w-full items-center h-screen justify-center">
            <h1>Login page</h1>
            <form
                onSubmit={(event)=>{
                    event.preventDefault();
                    console.log("event",event);
                    console.log("value:",userInputRef.current.value);
                }}
                className="flex flex-col bg-gray-500 p-6 gap-3"
            >
                <label htmlFor="username">Username:</label>
                <input ref={userInputRef} id="username" type="text" className="bg-white"/>
  
                <label htmlFor="password">Password</label>
                <input ref={passwdInputRef} id="password" type="text" className="bg-white"/>
  
                <Button className="bg-black text-white">Submit</Button>
            </form>
        </div>
    )
}
```
