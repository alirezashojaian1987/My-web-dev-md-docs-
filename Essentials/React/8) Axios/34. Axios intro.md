So far we use fetch for sending requests and receiving datas. Now we want talk a little bit about the downsides of it.

When sending requests, your network connection matters, for example if you get disconnected while sending request, your connection to server also fails and your request will not be sent. 
Or also a bad and slow connection may result in failing to send request or in other words, rejection.

These might happen while using fetch and promises which can be rejected under the circumstances.
As we said, can be rejected. What we mean is that you expect a promise to get rejected while receiving errors in the range of 400 or 500 which actually doesn't.

One of the downsides of fetch is that you have to set everything(including errors, conditions, management and etc.) manually, which is not efficient. 
And you always have to parse the date with JSON which is using code over and over.

And also you can't edit your files while sending requests.

Here comes **Axios** to save the day!

##### Using axios timeout

##### Making service out of axios
As mentioned above, we are able to make many different options with axios, but using them alone might result in copying and pasting the similar code over and over, which is not beneficial.
Also as mentioned before, **separation of concern** is important as well.

It's best that we make a folder called **services.**
To handle some matters like request timeout, which can we set a timer for a rejection if the client don't get their datas.
Or even using so many `.then` or `.catch` and put them all in one place.

Create a folder called services and a js file.
We need to create an axios instance, which helps us to use our axios on different places. In order to achieve that we can use a method called `axios.create()` which returns us an instance. There's a constant base url of our server. We can set our timeout.

Content type helps us to declare the content we want to receive from the API. There are multiple types and you can search about them.
```js
import axios from "axios";

export const apiClient=axios.create({
    baseURL:"http://localhost:3001",
    timeout:10000,
    headers:{
        "Content-Type":"application/json",
    },
})

export const getData=async(endpoint)=>{
    try{
        const response=await apiClient.get(endpoint);
        return response.data;
    } catch(error){
        throw new Error (error);
    }
}

//sending data
export const postData=async(endpoint,data)=>{
    try{
        const response=await apiClient.post(endpoint,data);
        return response.data;
    } catch(error){
        throw new Error (error);
    }
}

//updating data with patch
export const putData=async(endpoint,data)=>{
    try{
        const response=await apiClient.put(endpoint,data);
        return response.data;
    } catch(error){
        throw new Error (error);
    }
}

//deleting data
export const deleteData=async(endpoint)=>{
    try{
        const response=await apiClient.delete(endpoint);
        return response.data;
    } catch(error){
        throw new Error (error);
    }
}
```
The `apiClient` variable we created helps us to actually use the axios, but with the custom options we created and now we can use this on our different pages.

Collection.jsx before:
```jsx
import styles from "./Collection.module.scss";
import { useState } from "react";
import { useEffect } from "react";
import { Link,useParams, useSearchParams } from "react-router-dom";
import CollectionItem from "../../components/CollectionItem/CollectionItem";
import { apiClient } from "../../Services/ApiClient/ApiClient";

export default function Collection(){

    const [products,setProducts]=useState([]);
    const params=useParams();
    const [searchParams]=useSearchParams();
    const title=searchParams.get("title");

    useEffect(()=>{
        if(params.category)
            apiClient.get(`http://localhost:3001/products?category=${params.category}`).then(res=>{
                console.log(res);
                setProducts(res.data);
            }).catch((error)=>{
                console.log("Error occured:",error);
            })
    },[params.category])

    return(
        <>
            {title && <h1 className={styles.collectionTitle}>{title}</h1>}
            <div className={styles.collectionContainer}>
                {products?.map((item)=>(
                    <Link to={`${item.id}`}>
                        <CollectionItem key={item.id} {...item}/>
                    </Link>
                ))}
            </div>
        </>
    );
};
```
