##### NPM setup
NPM(node package management) is used for some online packages you need for your project
```bash
npm init
```
The code above will open some intro questions, you only need to press enter for now.
After that, there'll be a `package.json` file in your folder which will contain an object that has some infos about your projects. You can also type some scripts in it about for example(how to run it and...) and also you can type some commands for some operations. In the main key in the json, will determine which file is the main and should be read first. 
Now you can download other packages as well.
Like live server!
```bash
npm i live-server
```
Running the code above will install a folder which is node modules which contains so many libraries and modules.
The other one is a file named `package-lock.json`
Remember never to put those 2 files above in your git or other places.

```bash
npm install 
```
Running the code above will download the packages related to the project, based on the node module. For example when you download a file from git hub.

Now to run live-server
```bash
npx live-server
```

difference between npm and npx is that the npm is a source of many packages, npx is the package runner. You can also use npm for install and running packages but that won't be necessary. 
##### Create React app (CRA)
To use react, we need to create a react app and that will be possible using npm because as you know, react is a library and you need to use it better, or not using many configurations or tools adding them manually. You can use **create react app** so you won't need to do them above.

To start your project, enter the create react app website and
Open your terminal and type:
```bash
npx create-react-app #project_name
```
It'll take a while, so be patient! Also takes a lot of data :/

**Running the react project**
To run a react project, first you need to be in that folder, then you should open terminal and use command:
```bash
npm start
```
It will show the details. You can see the base react design page.

Now let's check crucial folders in our react project folder.
##### React folders
One of the important folders is the src folder that we have a lot to work with.
Most of the codes we work with are in this folder.
There is a node modules folder that contains packages we installed. There are so many packages.
Those packages are in the package.json file. In the dependencies in that file, contains important packages which are needed.

There are some scripts in the `package.json` folder. For example when we ran the `npm start` command, that command is in the json file. You can also make your own scripts in js or node.js as well.

In `eslinConfig` section are some regular expressions. You can also make some yourself, like every function in this folder should start with uppercase letter. In short, you can set your own rules.

There is a gitignore file as well and you know what it does :)

**public folder:** Contains some files. One of them is a html file, Which is our main html file. We should do our project in SPA way. One html and other data, pages and page contents are sent to server using AJAX. 
In the html there's a div with the id `root`. 

**Src folder:**
In the src folder there are multiple files. One of them is the index.js which is our project's entry point.
There's the root we talked about. 

The main file in the whole project is the index.js

##### Vite
You can use vite for your react project as well. It has less build time.
```bash
npm create vite@latest
```
Then you set a name.
Then there are some framework options, choose react. Then choose js for now. 
After the installation, you can get some command with h+enter. There'll be a menu of commands.

The main file in the project is the main.jsx 
For running a project, unlike the cra method, use this:
```bash
npm run dev
```
