##### SPA
Before, when client used to send a request to server, server would send the whole files back and the client's browser would have to download them and refresh the whole page. 
In other words, with every action, the whole process of sending request and downloading the whole page happens.

Requesting again or refreshing, would result the whole operation above, so this wasn't really beneficial. 

SPA(Single page application) functions in a way that after the first request, the other requests only work with AJAX and JSON. In other words, client and server only communicated with json and ajax after the first request.

With React, we have a single page, and we can work with DOM much easier.
