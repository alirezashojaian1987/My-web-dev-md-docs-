Before answering that let's try to understand the differences between library and framework.

Framework is a collection of tools which helps us create and design a website or etc.
It has a general and defined structure. When using framework, you have to code based on what is pre-defined, Which in frameworks, tools are mostly pre-defined and built-in.

Library is a tool which helps us to just create and design an specific part.
In libraries you can use other libraries for different purposes. 

React is a **UI library** and handling other things are on yours.

In stylings, you can also use other tools, and actually it's ok with React.
