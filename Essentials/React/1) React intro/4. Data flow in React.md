Data flow means that how changes and datas are in flow in React projects or how the datas moves or transports between components.

As we talked about it before, when we define and declare an state, react checks it and based and eventually on the state's change event(like an action trigger such as pressing a button and etc...), react renders the part we defined as the statement.

At first, when we create a component file, React uses the states and the **JSX** files to create the virtual DOM.

Data flow is always **one sided** in React(Parent to child only.)
