After you create your React project folder(here we are talking about vite) you can see a folder named src which contains multiple `.jsx` files and ...

When you open `main.jsx` file, you can see a component called **App**.
This component is between a wrapper component called `<StrictMode>` which is from react but we talk about it later.

App is actually the root or the parent of all files components in the project.

A react project is one HTML page with a div that has an id with `root` value, and we created an element with react-dom and that element which is a component, we use it in the main file.

##### `App.jsx`
The first time you open `App.jsx` there are some imports and an export.
We use import for modules or other tools.
We use export in order to use the functions or elements in other files.

The first function is `App()`.
There you can see a return and a HTML structure like code which is not actually(or completely) HTML.

You can run the page which will show you a designed page. The code is default when the project is being created so you won't need it and can clear the codes.

Anything you write inside the `return` will be shown in the running server.
The virtual dom show the page with the help of react dom on the browser and that Dom is created with the contents of the jsx.

Another difference of jsx and html is the class. In html we have class but in jsx it's called className. It is used for styling.

##### Rendering dynamic values
JSX is actually a combination of html and js.

when you need to use the js inside the `return` which has html code, to render them you need to put them inside `{}`. like values, variables, functions and etc.
```jsx
<h2>{5+5}</h2>
<h2>{Math.random()}</h2>
```

Using defined functions:
```jsx
import './App.css'
  
function App() {
  const welcome_msg=()=>{
    return "Hello world"
  }
  
  return (
    <>
      <h1>{welcome_msg()}</h1>
    </>
  )
}
  
export default App
```

##### Creating components
When creating component functions, they need to start with a capital letter.
```jsx
import './App.css'
  
function App() {
  return (
    <>
      <Heading/>
      {//or <Heading><Heading/> 1*}
    </>
  )
}
  
export default App
  
const Heading=()=>{
  return(
    <>
      <h1>Hello my niggas</h1>
    </>
  )
}
```

*Note:* When we don't need anything inside the element, we can use the self closing form of the tag. like the example above.

Another important thing is that a component can only return one element.
The element is better to be a wrapper element like `div` which can hold other elements and tags inside it.

*!Note:* Remember, you shouldn't create components inside other components! It's better to have a reusable component file that can be used in multiple places. Or having a ordered file is better.
