As we mentioned earlier, components should be reusable, so we can use them on other places as well.
For example we got a list from back-end, and we want to render it. Obviously we can't use the last component.

So we need to move every content one layer upper.
We need to get the list items.
Most of the times, we get and fetch the datas.

In your `list.jsx`
```jsx
import { useState } from "react";
  
const List=(props,onClick)=>{
    const [sel_item,setSel_item]=useState(0);
    const handle_click=(index,item)=>{
        setSel_item(index);
        onClick(item);
    }
    return(
        <>
            <label>Best high tech companies</label>
            <ul>
                {props.items?.length?(
                    props.items.map((item,index)=>(
                        <li
                            onClick={()=>handle_click(index)}
                            key={item}
                            className={sel_item===index ? "selected_item" : ""}
                        >
                            {item}-{index}
                        </li>
                    ))
                ):(
                    <div>There is no item</div>
                )}
            </ul>
        </>
    );
};
  
export default List;
```

Sometimes reusing the prop word can be annoying, so we can actually destructure it at first.
```jsx

const List=({items},onClick)=>{

    const handle_click=(index,item)=>{
        setSel_item(index);
```

or this:
```jsx
import { useState } from "react";
import "./List.css";
export default function List({items}){
    const [selItem, setSelItem]=useState(0);
    const handleClick=(index)=>{
        setSelItem(index);
    }
  
    return(
        <>
            <label>The best high tech companies</label>
            <ul>
                {items.length?(
                    items.map((item,idx)=>(
                        <li
                            key={item}
                            onClick={()=>handleClick(idx)}
                            className={selItem===idx ? "selectedItem" : ""}
                        >
                            {item}
                        </li>
                    ))
  
                    ) : (
                        <div>There is no item...</div>
                )}
            </ul>
        </>
    )
}
```
But remember, when destructuring, the destructured prop's name should be the same as the attribute element in the parent component.

This is the best method.
