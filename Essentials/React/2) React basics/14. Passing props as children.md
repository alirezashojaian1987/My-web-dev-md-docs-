In app.jsx
```jsx
import './App.css'
import List from "./components/list";
import Card from './components/Card';

const companies=["Tesla","Microsoft","Sony","Apple"];
function App() {
  const handle_sel_item=(item)=>{
      console.log(item);
  }
  return (
      <div>
        <Card></Card>
        <List
          items={companies}
          onClick={handle_sel_item}
        />
      </div>
  );
}
  
export default App
```
Now if you try to put all you list items in the card, it won't show anything. We need to pass the props as children.

```jsx
const Card=({children})=>{
    return <div className="card">{children}</div>
};
  
export default Card;
```
Now in app.jsx you can put the list in the Card tag.

Remember, when using the component's tag in the open and close form, everything between those two are children, on the other hand when using the self closing form, they are props.
