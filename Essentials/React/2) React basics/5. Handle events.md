Pressing one item will change it's color but doing it again won't do. It's because as we mentioned before, virtual DOM considers state changes which here didn't happen. 

`useState()` is a built-in method which returns two things: state, the action that changes the state. And the set state which assigns the value to the state.
You need to import it, but you can also write the function first, and your ide types the import automatically. 
You can destructure the function as well.

But this looks so unordered and messy.
So we can define a function and then use it in the event we defined for the list items.

```jsx
import { useState } from "react";

const List=()=>{
    const [sel_item,setSel_item]=useState(0);
    const items=["Tesla","Microsoft","Sony","Apple"];
    const handle_click=(index)=>{
        setSel_item(index);
    }
    return(
        <>
            <label>Best high tech companies</label>
            <ul>
                {items.length?(
                    items.map((item,index)=>(
                        <li
                            onClick={()=>handle_click(index)}
                            key={item}
                            className={sel_item===index ? "selected_item" : ""}
                        >
                            {item}-{index}
                        </li>
                    ))
                ):(
                    <div>There is no item</div>
                )}
            </ul>
        </>
    );
};
  
export default List;
```
