Let's work on the previous project.
Considering you want to add a label to the ul you created.
```jsx
const List=()=>{
  
    const items=["Tesla","Microsoft","Sony","Apple"];
  
    return(
        <label>Best high tech companies</label>
        <ul>
            {items.map((item)=>{
                return <li>{item}</li>
            })}
        </ul>
    );
};
  
export default List;
```
There'll be an error next to the label tag you use, which says: JSX expressions must have one parent element.
Which means you can't return multiple separated elements.
But what you can do to avoid it:
1. Put the label inside the ul.
2. Or put all of them inside a div tag.
The downside of using a div as a solution, is that you are adding a layer in the DOM tree.

So now what we really wanna do XD?

We can use **React fragment**
Basically, you need to do this:
```jsx
import { Fragment } from "react";
  
const List=()=>{
  
    const items=["Tesla","Microsoft","Sony","Apple"];
  
    return(
        <Fragment>
	        <label>Best high tech companies</label>
            <ul>
                {items.map((item)=>{
                    return <li>{item}</li>
                })}
            </ul>
        </Fragment>
    );
};
  
export default List;
```
Now if you use inspect, there you can see the label and the ul. No sign of a div, nor the Fragment you used.

##### Best way?
But the best way is:
```jsx
const List=()=>{
    const items=["Tesla","Microsoft","Sony","Apple"];
    return(
        <>
	        <label>Best high tech companies</label>
            <ul>
                {items.map((item)=>{
                    return <li>{item}</li>
                })}
            </ul>
        </>
    );
};
export default List;
```
This is actually the modern method.
