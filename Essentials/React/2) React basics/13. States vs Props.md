Props are entries of a component. Or you can say the given arguments of a component.
They are passed from parent to child but the other way is not possible.

States are like local variables in the components and they can hold value and datas.
Same as props, you can pass it to the child component.

Props are immutable, which means that you can only use the given data but you cannot change it.
States on the other hand, are mutable and can be overwritten.

Their goals are different, states are often used for storing data while props are used to contain and transfer logic or condition to the component so it can apply them, or when you need the parent component to use the child component. (We call the parent, **Consumer** in this matter)

You can also pass both the states and props to lower layers as well(but this is called props drilling and is not really beneficial, you'll learn later about this).

As we talked about virtual Dom and how it works before, each time a re-render occurs in a component, all of it's child components also get re-rendered so it matters that where to use states and props.
