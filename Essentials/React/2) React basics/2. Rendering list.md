We know that we can separate our components and pages in React much easier, in order to prevent the code becoming messy and hard to read.

Let's create our first component. 
Create a folder in src folder, named components. It's proper to name this folder in every React project.
Create a jsx file. Write a component in it, it can be anything:
```jsx
const List=()=>{
    return(
        <ul>
            <li>1st</li>
            <li>2nd</li>
            <li>3rd</li>
            <li>4th</li>
        </ul>
    );
};
  
export default List;
```

Then add it in the `App.jsx`
```jsx
import './App.css'
import List from "./components/list";
  
function App() {
  return (
      <div>
        <List/>
      </div>
  );
}
  
export default App
```
*Note:* When importing, you can use any name you want but remember the first capital letter.(Here is List, but you can also use List_items or whatever you want.)

Now run it and your list is shown.
You can change the style in the APP.css and the index.css

##### Make your components more reusable
As mentioned before, one of the important things about the components is the reusability. The list file we created has default values.
If we want to use List file in other parts as well, it's better to have a structure as below.(The items variable is an example)
```jsx
const List=()=>{
  
    const items=["Tesla","Microsoft","Sony","Apple"];
  
    return(
        <ul>
            {items.map((item)=>{
                return <li key={item}>{item}</li>
            })}
        </ul>
    );
};
  
export default List;
```
*!Note:* Remember that you can't use for loops inside the `return()` and as mentioned before, you need to use **declarative** methods. Here we use `map()` which is an Array method

Using `key` in the item's attributes within the `map` iteration is very important. You can check on console in the chrome.
Why it matters is because when for example changing the list, the whole **DOM** is changed and a new list is returned because it couldn't realize which key is changed. But with keys, it can track and find the changed list item.

*Note:* Never pass index as a key. Cause it never guaranties that the items are rendered ordered.
