Design pattern as it's called, tells us about patterns and algorithms for coding.
A solution that is used by many programmers that help us to create and develop our projects in a better way. 

First of all, it's not a rule, it's just a common way that is used by many people. So when you consider these in your code, other people will realize and understand your code in an easier way.

In other words, it helps with the code's readability as well.

It helps with maintainability, reusability, scalability, code organization and performance optimization as well.

Design pattern is defined for all programming languages, many projects need it.
