Higher order comp(HOC), is like the higher order functions inside Js, where you could use functions inside another functions(closures). 

HOC helps us in UI with that logic.
When some UIs are used in multiple components, we can avoid that by using HOC pattern.

For example, we have a loading component that is used within many pages. We shouldn't rewrite the code over and over again.

Authentication also can be handled as well.
